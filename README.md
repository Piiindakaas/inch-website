# INCH_ website

Statische one-pager voor INCH_, gehost op GitHub Pages.

- Content: `index.html`
- Opmaak: `assets/css/style.css`
- Live zetten: merge naar `main`, de workflow in `.github/workflows/pages.yml` doet de rest.

Lokaal bekijken:

```bash
python3 -m http.server 8080
```

en open http://localhost:8080.
